This folder is for OAuth examples only.

DO NOT commit real secrets to source control.

Supported runtime locations:
- environment variables such as FYLORRA_ONEDRIVE_CLIENT_ID
- ~/.fylorra/oauth_apps.json
- ~/.fylorra/gdrive_client_secrets.json

Use google_client_secrets.example.json or onedrive_client_id.example.txt as the
shape for local credentials. Keep the real files outside the repository.
